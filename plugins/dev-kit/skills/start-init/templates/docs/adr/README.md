# سجل قرارات المعمارية (ADR)

ملف قصير لكل قرار تقني مهم: السياق، والقرار، والبدائل المرفوضة وسببها. الهدف أن أي شخص يدخل المشروع لاحقاً يفهم لماذا الأشياء مبنية بهذا الشكل.

## القواعد

- **قرار جديد = ملف جديد** من `0000-template.md`، بالرقم التالي: `ADR-001-<slug>.md`.
- **ممنوع تعديل ADR معتمد.** لو القرار تغيّر، اكتب ADR جديداً حالته "معتمد"، وغيّر حالة القديم إلى "اتلغى بـ ADR-xxx".
- **الحالات:** مقترح · معتمد · اتلغى.
- القرار المقترح الذي يحتاج صاحب المشروع يُسجَّل أيضاً في `docs/PROJECT_MEMORY.md` القسم 4.
- كل ADR جديد يُضاف للفهرس أدناه وإلى `docs/PROJECT_MEMORY.md` القسم 7.
